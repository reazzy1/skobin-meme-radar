# Skobin Meme Radar — Telegram cloud bot

Cloud version of the radar plus Telegram bot.

Commands:
- /start — subscribe the current chat
- /radar — current candidates
- /signals — recent signals
- /status — scanner / GMGN status
- /bets — virtual test bets
- /stop — unsubscribe

Secrets are provided by the hosting service as environment variables:
TELEGRAM_BOT_TOKEN, optional TELEGRAM_CHAT_ID, and GMGN_API_KEY.
